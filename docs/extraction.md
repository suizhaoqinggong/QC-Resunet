# 提取边界

## 保留

训练和评估循环、接口协议、组件注册和工厂、TOML 合并、设备和种子管理、AMP、DDP、早停、模型权重选择、配置与数据划分快照、TensorBoard 和 JSONL 日志。

数据保留合成数据与 BraTS 的 raw/NPZ/NPY、受试者分组、固定 ID 列表、3D 增强、2D 切片适配。任务保留多标签分类和标准多类分割，指标保留通用指标及可选 BraTS WT/TC/ET。

## 独立边界

所有运行代码使用 training_framework 包名。依赖和命令由本项目自己的 pyproject.toml 和 uv.lock 定义，环境由本项目自己的 uv sync 建立。没有指向其他项目的源码链接、sys.path 注入、外部模型源码路径、权重路径、实验患者列表或共享 Git 历史。

算法模型、模型适配器、特定论文的损失组合与后处理、消融配置、历史实验、论文和作图脚本不包含在提取范围中。模型目录仅保留分类接口示例并新增微型分割接口示例。

## 提取时修正

- 数据类别数由 class_names 注入，合成数据样本 ID 区分不同划分。
- 所有划分的指标使用同一组配置参数，且拥有独立实例。
- AUC 指标补全曲线起点并合并相同分数的阈值；AUPRC 明确为阶梯积分（Average Precision），避免完美预测低于 1。
- dice 使用真正的 Soft Dice；默认分割使用标准 CE，不加载特定论文损失。
- DDP 所有 rank 都记录最佳指标与最佳权重路径，fit 在加载权重前同步。
- 去掉会额外消耗随机数及影响 BatchNorm 的无条件预热步骤。
- 空训练/评估加载器与未知监控指标显式报错。
- 分类/分割 Task 不再静默吞掉拼错的配置参数。
- BraTS 依赖延迟导入，默认路径改为项目相对路径。
- 使用独立插件注册入口接入新模型。

## 当前能力边界

Checkpoint 为权重与评估元数据保存，不是完整续训快照。Evaluator 是批次直接前向，不提供整图滑窗或不确定性推理。多标签分类和多类分割有默认 Task；单标签分类、二分类单通道分割、其他任务可通过插件提供专门 Task。
